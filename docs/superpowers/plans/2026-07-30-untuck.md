# Untuck Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Forgotten (never-opened saves older than 30 days) as a library destination and Surprise me as a toolbar action that opens a random item from the current visible set, with open tracking via `lastOpenedAt`.

**Architecture:** Pure Domain helpers (`UntuckRules`) own forgotten membership and surprise candidate selection. `Bookmark.lastOpenedAt` plus `BookmarkRepository.markOpened` own persistence and CloudKit-friendly `modifiedAt` bumps. UI reuses `LibraryDestination` / `LibraryGridView` and routes every open through a single stamp-then-open path so cards, commands, and Info stay consistent.

**Tech Stack:** Swift 6, SwiftUI, SwiftData, CloudKit private DB (additive field), XCTest. No third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-07-30-untuck-design.md`

## Global Constraints

- Support iOS/iPadOS 18 and macOS 15.
- System Apple frameworks only; no package dependencies.
- Keep `BookmarkCollections` target, folder, and bundle identifier namespaces unchanged.
- Keep App Group `group.com.loweffortapps.BookmarkCollections` and CloudKit container `iCloud.com.loweffortapps.BookmarkCollections` unchanged.
- Forgotten = `deletedAt == nil && lastOpenedAt == nil && createdAt <= now - 30 days`.
- 30-day threshold is a fixed constant (not Settings).
- Only in-app open (link open or image viewer presentation) stamps `lastOpenedAt`; invalid URL must not stamp.
- Surprise me uses the same set the grid shows (destination ∩ search); disabled when empty; hidden/disabled for Recently Deleted.
- JSON backup round-trips optional `lastOpenedAt` without bumping `BackupDocument.currentVersion` (missing key → nil).
- HTML export unchanged (no open metadata).
- Share extension continues to compile with the additive model field; it does not need Untuck UI or `UntuckRules`.
- Dual-target build verification required after model/repository changes:
  `BookmarkCollections` and `BookmarkShareExtension`.
- Branch before feature work; do not commit feature code to `main`.
- Production CloudKit schema deploy for `lastOpenedAt` is a ship gate for Production-signed builds (document in DECISIONS/CHANGELOG; do not claim it from local tests alone).

```swift
import Foundation

enum UntuckRules {
    static let forgottenAge: TimeInterval = 30 * 24 * 60 * 60

    static func isForgotten(_ bookmark: Bookmark, now: Date = Date()) -> Bool {
        guard bookmark.deletedAt == nil else { return false }
        guard bookmark.lastOpenedAt == nil else { return false }
        return bookmark.createdAt <= now.addingTimeInterval(-forgottenAge)
    }

    static func surpriseCandidates(
        in bookmarks: [Bookmark],
        destination: LibraryDestination,
        searchText: String
    ) -> [Bookmark] {
        bookmarks.filter { destination.matches($0, searchText: searchText) }
    }
}
```

```swift
private var surpriseCandidates: [Bookmark] {
    UntuckRules.surpriseCandidates(
        in: bookmarks,
        destination: destination ?? .allItems,
        searchText: searchText
    )

private func surpriseMe() {
    guard let bookmark = surpriseCandidates.randomElement() else { return }
    openBookmark(bookmark)
}
```
