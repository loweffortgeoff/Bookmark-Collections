**Goal:** Deliver Tucked v1.1.3 (Cycle 1) — clearing remaining non-schema backlog fixes (`F20`, `F22`, paywall test-flag verification), adding capture awareness and low-friction entry ("Already tucked" notice, clipboard URL assist, iOS/iPadOS Home Screen Quick Actions), and shipping Settings & library-health upgrades ("We Also Make", device-observed iCloud sync timestamps, and an opt-in ephemeral "Check for Broken Links" sweep).

## Review Focus

Five implied input classes and failure modes most likely to bite users — each pinned by a test in its owning task:

1. **Non-square image panning, zoomed sheet dismissal & resize (Task 3):** Panning a tall portrait or ultra-wide image at `1.2×–8×` must clamp to actual fitted-image overflow (zero horizontal drift when scaled width ≤ viewport), disable iOS interactive sheet dismissal while `zoom > 1` without blocking swipe-to-dismiss at `1×`, and re-clamp cleanly on window resize/rotation.
2. **Mixed/empty/limit-hitting URL drops & Finder file skips (Task 4):** Dropping a batch mixing valid HTTP/HTTPS URLs, `mailto:`/malformed URLs, and Finder `file://` URLs onto an empty collection must assign new links to that collection, preserve organization on already-saved links, skip `file://` URLs silently (image drop is out of scope), report non-file invalid URLs without aborting, and keep partial saves when hitting the free limit.
3. **Clone-safe focus & clipboard privacy (Tasks 5 & 6):** Focusing an existing bookmark from Add Link's "View" action must use `PersistentIdentifier` (clone-pair safe); opening Add Link on iOS with plain text/image/empty clipboard must never trigger the paste banner; macOS clipboard reads must gate on `detectPatterns` (`macOS 15.4+`) and disable under `-ui-testing`.
4. **Cold-launch Quick Actions & draft/paywall/summary protection (Task 7):** A Home Screen Quick Action launched from a terminated app must arrive once via `scene(_:willConnectTo:options:)` into `MenuBarRouter.shared` and execute when `LibraryRootView` mounts; warm-resume Quick Actions or Mac Menu Bar actions arriving while an editor draft, `PaywallView`, or `dropSummary` is open must be dropped without discarding unsaved input.
5. **CloudKit synchronous registration & captive-portal/offline link sweeps (Tasks 2 & 8):** `SyncHealthMonitor` must register its `NSPersistentCloudKitContainer.eventChangedNotification` observer synchronously *before* `ModelContainerFactory.make(...)` and ignore failed/in-progress events; "Check for Broken Links" must await the first `NWPathMonitor` update, abort on DNS/captive-portal storms rather than flagging the entire library, treat `401`/`403`/`429`/`5xx`/TLS errors as uncertain, and cancel `GET` fallback transfers after receiving headers.

Key implementation details:
1. Default `ConnectivityCheck`:
   - Start `NWPathMonitor`, await the **first** `pathUpdateHandler` callback (using a single-resume continuation guarded by a short ~1.5 s timeout, calling `monitor.cancel()` immediately upon resolution — never read `monitor.currentPath` synchronously right after `start()`).

## Risks & Mitigations

| # | Risk | Impact | Mitigation |
|---|---|---|---|
| 1 | **SwiftData + `NSPersistentCloudKitContainer.eventChangedNotification` delivery** (`Spec 3.2`) | SwiftData wraps Core Data's CloudKit container internally; if notifications are not posted or are filtered differently on iOS 18 / macOS 15, timestamps stay stuck at "Not yet observed". | Run Task 2 immediately after Task 1, register observer **synchronously** before `ModelContainerFactory.make(...)`, and verify on signed real iPhone + Mac hardware via `OSLog`. Do not ship fabricated timestamps if events don't fire. |
| 2 | **Pasteboard privacy prompts on iOS & macOS 26/27** (`Spec 2.2` & `2.3`) | Programmatic `UIPasteboard.general.string` (even from a Quick Action) shows the iOS "Allow Paste" alert; automatic `NSPasteboard` reads may also prompt on macOS 26/27. | On iOS Add Link, gate with `detectPatterns([.probableWebURL])` and use zero-banner `PasteButton` (Q3); on iOS "Save from Clipboard" Quick Action, pre-fill via direct read accepting the explicit-action system prompt (Q4). On macOS, gate with `if #available(macOS 15.4, *)` `NSPasteboard.general.detectPatterns(for: [.probableWebURL])` and verify on macOS 27.2. Suppress all reads under `-ui-testing`. |
| 3 | **Add Link blank pickers on Return over already-tucked links** (`Spec 2.1` + `2.2`) | Pressing Return on an already-tucked link in Add Link applies blank form defaults (`nil` collection, `isFavorite = false`) while Q2 is kept blank. | Watch during hands-on testing after implementation (Geoffrey chose to leave blank until seeing how the app performs); easy 1-line follow-up if it bites in daily use. |
| 4 | **SwiftUI `App` lifecycle dropping or double-firing iOS Home Screen Quick Actions** (`Spec 2.3`) | `UIApplicationDelegate.application(_:performActionFor:)` is ignored in SwiftUI scene-based apps, and enqueuing in both `configurationForConnecting` and `willConnectTo` double-fires. | Wire `UISceneConfiguration` + `QuickActionSceneDelegate` writing into `MenuBarRouter.shared`, with cold launch strictly in `scene(_:willConnectTo:options:)` and warm resume strictly in `windowScene(_:performActionFor:)`. |
| 5 | **Image Viewer sheet-dismissal conflict while zoomed** (`F20`) | Dragging down while zoomed inside an iOS `.sheet` can pull the sheet closed; unconditional drag at `1×` blocks dismissal. | Add `.interactiveDismissDisabled(zoom > 1)` and `.gesture(panGesture, isEnabled: zoom > 1)` (iOS 18 / macOS 15), with pure `ImageViewerTransform` edge clamping. |
| 6 | **Broken-link sweep captive-portal DNS storms & large `GET` downloads** (`Spec 3.3`) | Captive portals / broken VPN DNS report `NWPathMonitor.satisfied` while every lookup returns `cannotFindHost` (risking mass soft-delete via "Move All"); `GET` fallback could buffer large files. | Await first `NWPathMonitor` update with timeout, abort as offline on multi-host DNS storms when zero hosts respond, use `Range: bytes=0-0` + delegate `.cancel` after response headers on `405`/`501` `GET` fallback, and soft-delete only. |
| 7 | **Share Extension target compilation drift** (`Task 5`) | New files under `BookmarkCollections/` do not compile into `BookmarkShareExtension` automatically. | Keep `ExistingLinkMatch` inside `BookmarkRepository.swift` (already in `AA10000000000000000000B2`) and build `BookmarkShareExtension` for both iOS Simulator and macOS. |
| 8 | **iOS Settings UI test fragility** (`Task 9`) | Adding rows above `About` pushes `settings.privacyPolicy` further below the fold on iPhone's lazy `Form`. | Update `testSettingsExposesImportExportAndICloudStatus` to use a bounded scroll-until-visible loop. |
