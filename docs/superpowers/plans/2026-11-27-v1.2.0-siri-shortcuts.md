# Tucked v1.2.0 Siri, Shortcuts & Spotlight Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Execution (Geoff, 2026-11-27):** Native (superpowers:executing-plans). **Do not start until v1.1.3 (18) is through App Review on iOS and macOS.** A rejection fix must land on a clean `main`.

**Goal:** Ship the v1.2.0 App Intents suite (12 intents, 2 entities, static snippets, 8 App Shortcuts, CoreSpotlight) in the main app target with no schema change.

**Architecture:** All library logic lives in one testable `@MainActor` layer (`IntentLibrary`, plus one new `BookmarkRepository` method). Intents, entities, and snippet views in `BookmarkCollections/Intents/` are thin wrappers over it. Foreground navigation reuses `MenuBarRouter`. Spotlight uses hand-built `CSSearchableItem`s, so a tap can be routed deterministically.

**Tech Stack:** Swift 6, SwiftUI, SwiftData, AppIntents, CoreSpotlight, XCTest.

**Spec:** [Engineering design](../specs/2026-11-27-v1.2.0-siri-shortcuts-design.md) (the how, and the decisions numbered 1–15) and [product spec, Cycle 2](../specs/2026-11-23-v1.1.3-and-v1.2.0-spec.md#cycle-2--v120-siri-shortcuts--spotlight) (the what). Read both.

## Global Constraints

- Branch `dev/v1.2.0` from `main`. Geoff pushes. One commit per task.
- Deployment floor stays `IPHONEOS_DEPLOYMENT_TARGET = 18.0` and `MACOSX_DEPLOYMENT_TARGET = 15.0`. Gate any iOS/macOS 26+ API with `@available` / `#available`. Read `references/execution-modes.md` in the `xcode-integration:app-intents-whats-new-27` skill before Task 10.
- No-open intents declare no execution mode (the background default). Only the hidden helper intent in Task 10 and `OpenCollectionIntent` set `openAppWhenRun = true`.
- No change to `@Model` stored properties, entitlements, or the StoreKit config.
- New files go in `BookmarkCollections/Intents/`. The synchronized folder adds them to the app target only. Never add intent code to the nine Share Extension files, apart from the one `BookmarkRepository` method in Task 5.
- Entity IDs: `BookmarkAppEntity.id == Bookmark.id`, `CollectionAppEntity.id == BookmarkCollection.id`. `AppEnum` raw values and phrase text are frozen once shipped.
- `perform()` hops to the main actor with `await MainActor.run { … }` for every SwiftData access. Never build a `ModelContainer` in an intent; use `LibraryStore.shared` (Task 1).
- Never fetch from the network inside an intent, a snippet view, or the Spotlight indexer.
- English only (the project has no string catalog). System styles and semantic colors only.
- **Build check after every task** (both schemes):
  `xcodebuild -project BookmarkCollections.xcodeproj -scheme "BookmarkCollections" -destination 'generic/platform=iOS Simulator' build`
  `xcodebuild -project BookmarkCollections.xcodeproj -scheme "BookmarkShareExtension" -destination 'generic/platform=iOS Simulator' build`
- **Focused tests** (`TEST` below):
  `xcodebuild test -project BookmarkCollections.xcodeproj -scheme BookmarkCollections -destination 'platform=iOS Simulator,name=iPhone 18 Pro,OS=27.2' -parallel-testing-enabled NO -collect-test-diagnostics never -only-testing:BookmarkCollectionsTests/<Class>`
- Tests follow the existing style: XCTest, `@MainActor final class`, `ModelContainerFactory.make(inMemory: true, cloudKit: false)`.
- Stop at the end of each stop (marked **STOP**) and show Geoff what changed, how to check it, and what comes next.

## Review Focus

1. **Free limit at exactly 10 active items.** Saving a new link or snippet fails with the limit dialog. Re-saving an existing active link still succeeds (an update does not count). Restoring from Recently Deleted fails. Pinned in Task 5 and Task 6.
2. **A saved shortcut points to a bookmark that has since been deleted or purged.** Set Favorite, Move, and Open Bookmark fail with "That bookmark is no longer in Tucked." They never act on the Recently Deleted copy. Pinned in Task 2 (`activeBookmark`) and Task 6.
3. **Loose URL input to Save Link** (`example.com`, `  https://x.com  `, `not a url`). Schemeless input is fixed up the way the Add Link form does it. Invalid input gives a dialog, not a crash. Pinned in Task 6.
4. **Pre-F1 clone pairs** (two rows with the same `id`). Entity lookups and lists return one entity per `id`: the oldest active row. Pinned in Task 2.
5. **Empty results** (empty library, no favorites, nothing forgotten, no Surprise candidates, nothing on this day). Each read intent returns an empty list and a friendly dialog. Pinned in Task 2 and Task 7.

### Task 2: Read queries

**Interfaces:**
- Produces:
  ```swift
  enum IntentSort: String, CaseIterable, Sendable { case dateAdded, dateModified, lastOpened, title }
  @MainActor struct IntentLibrary {
      init(context: ModelContext, now: Date = .now, calendar: Calendar = .current)
      static let limitRange = 1...50
      func activeBookmark(id: UUID) -> Bookmark?          // oldest active row with that id; nil if only deleted rows
  ```
