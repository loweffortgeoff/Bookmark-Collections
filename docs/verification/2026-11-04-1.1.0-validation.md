- Under XCTest the app launches with a menu bar but no window. All 26 failure hierarchy dumps have no `Window` element. A test recording shows Tucked frontmost with no window.
- Not caused by the menu bar commit: `testAppLaunches` fails the same way at `c4c2747`, the commit before it.
- Not caused by the running `~/Applications/Tucked.app` copy: quitting it did not change the result.
- Not fixed by `.defaultLaunchBehavior(.presented)` on the library `Window` (tried, reverted).
- No saved window state exists for the bundle ID.
- Launched directly with `open` and `-ui-testing`, the same Debug build shows its "All Items" window (900 x 450, on screen). The app opens its window outside XCTest; the failure is in the XCTest launch on this Mac.
- Unchecked: whether the window opens on another Space or display, and whether XCTest automation or Accessibility permission changed after the 04:18 run that recorded 17 passes.
